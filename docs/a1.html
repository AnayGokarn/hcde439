Assignment 1: Blink!

A three-LED "traffic light" chase pattern for the holiday light company: red, yellow, and green LEDs light up one at a time, each for one second, in a repeating loop.

Schematic

Resistor Calculation

Each LED and its resistor form their own branch, and the three branches are wired in parallel between their Arduino pin and a shared ground. Because they are in parallel, each branch sees the full 5 V from its pin and can be calculated on its own.

  • Supply voltage (Arduino digital pin HIGH): Vs = 5 V
  • LED forward voltage (typical for a 5 mm red/yellow/green LED): Vf ≈ 2 V
  • Target LED current: I = 20 mA = 0.020 A

Kirchhoff's Voltage Law around one branch (pin → resistor → LED → ground):

Vs = VR + Vf
VR = Vs − Vf = 5 V − 2 V = 3 V

Ohm's Law for the resistor, which carries the same current as the LED in series with it:

R = VR / I = 3 V / 0.020 A = 150 Ω

So 150 Ω is the resistance that keeps each LED at 20 mA. I used 100 Ω resistors, which gives I = 3 V / 100 Ω = 30 mA per LED. That is above the LEDs' typical 20 mA rating but below the Arduino pin's 40 mA absolute maximum, and since only one LED is on at a time in this pattern, the board only ever supplies about 30 mA in total.

Circuit

Firmware

// Store the pin number for the red LED (digital pin 13)
const int LED_1 = 13;
// Store the pin number for the yellow LED (digital pin 12)
const int LED_2 = 12;
// Store the pin number for the green LED (digital pin 11)
const int LED_3 = 11;

// setup() runs once when the Arduino powers on or resets
void setup()  {
    // Configure the red LED's pin as an output so it can supply voltage
    pinMode (LED_1, OUTPUT);
    // Configure the yellow LED's pin as an output
    pinMode (LED_2, OUTPUT);
    // Configure the green LED's pin as an output
    pinMode (LED_3, OUTPUT);
}

// loop() runs over and over forever after setup() finishes
void  loop() {
    // Turn the red LED on (pin set to 5V)
    digitalWrite (LED_1, HIGH);
    // Turn the yellow LED off (pin set to 0V)
    digitalWrite (LED_2, LOW);
    // Turn the green LED off
    digitalWrite (LED_3, LOW);
    // Hold this state for 1000 milliseconds (1 second)
    delay (1000);
    // Turn the red LED off
    digitalWrite (LED_1, LOW);
    // Turn the yellow LED on
    digitalWrite (LED_2, HIGH);
    // Keep the green LED off
    digitalWrite (LED_3, LOW);
    // Hold this state for 1 second
    delay (1000);
    // Keep the red LED off
    digitalWrite (LED_1, LOW);
    // Turn the yellow LED off
    digitalWrite (LED_2, LOW);
    // Turn the green LED on
    digitalWrite (LED_3, HIGH);
    // Hold this state for 1 second, then loop() starts over with red
    delay (1000);
}

Circuit Operation

Questions

1. Voltage across the LEDs over time

Each LED has about 2 V (its forward voltage) across it while its pin is HIGH and 0 V while its pin is LOW. The pattern repeats every 3 seconds.

2. How many LEDs could you blink independently, and how much current would that draw?

The Arduino Uno has 20 digital I/O pins (D0–D13 & A0–A5). However, pins D0 & D1 are for USB meaning that I would be able to blink 18 LEDs independently simultaneously with one on each pin. To calculate current draw I would do 18 × 20 mA = 360 mA. This is more than the Arduino's 200 mA limit so to light them all at once I would require larger resistors or to activate them in a pattern where only a few LEDs are on at once.

3. How fast do you need to blink the LEDs until you can no longer tell they are blinking?

I tested my vision by changing the delay() values for a circuit with a single LED. When the delay was 20 ms (25 blinks per second) I could still see the light flicker. However, when I changed the delay() to 10 ms (~50 blinks per second) the LED looked like it was constantly on just dimmer. So an LED needs to blink at least 50 times a second before I can no longer tell they are blinking.
